# FreshNest Cleaning Website Demo

A responsive, single-page cleaning company website demo built with HTML, CSS and vanilla JavaScript.

## Preview

Open `index.html` in a browser. Internet is required for the Google Fonts and remote Unsplash demo photos. The rest of the website files are local.

## Included
- Responsive navigation with a mobile menu
- Hero section and calls to action
- Cleaning services cards
- About section and process steps
- Booking request form with browser validation
- Sample testimonials (replace before launch)
- Responsive styling and reduced-motion support

## Important before publishing
This is a visual/front-end demo, not a live booking system. The form does **not** send or save customer information. Connect it to a trusted form service or backend before accepting real requests. Replace the sample brand, photos, testimonials, contact details, service area, privacy policy and business claims with accurate information.
